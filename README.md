## Installation

### Using npm(ES6 module):
```alias
npm i w-aggrid-vue
```

### In a browser(UMD module):

Add script for vue.
```alias
<script src="https://cdn.jsdelivr.net/npm/vue@2.x/dist/vue.min.js"></script>
```

Add script for w-aggrid-vue, ag-grid-community and ag-grid-vue have been bundled into the umd file(css included), only vue is required.
```alias
<script src="https://cdn.jsdelivr.net/npm/w-aggrid-vue@2.0.70/dist/w-aggrid-vue.umd.js"></script>
```
