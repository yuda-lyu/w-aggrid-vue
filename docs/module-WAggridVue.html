downloadData(optopt) → {Array}

Description:

  • 下載表格全部數據為Excel檔案，欄位依opt.keys之順序且含隱藏欄，數據為opt.rows全部列(不受表頭過濾、filterall與排序影響)，不含置頂置底列；不需表格就緒即可呼叫，惟opt變更後須待$nextTick再呼叫，否則取得變更前之數據

    處理順序：欄位keys → opt.funGetKeysHook → 依keys由各列取值並依opt.kpCellFormat格式化 → opt.funGetLtdtHook → 轉為二維陣列並加上表頭列 → opt.funGetMatHook → 觸發下載；各掛鉤皆須同步回傳，不支援Promise

  • 開啟上傳視窗讀取Excel檔案，並以其數據取代或附加於表格數據

    須於使用者操作(例如點擊)之事件處理函數內呼叫，否則瀏覽器不開啟選檔視窗，回傳之Promise亦不會結束。讀檔規則：讀取.xlsx之指定分頁，首列為表頭，表頭須與opt.keys完全相同(含大小寫與空白)或經表格之opt.kpConvertKeysWhenUploadData轉換，空表頭之欄略過，表頭重複或轉換後同名時後者覆蓋；整列皆無值之列略過，含空字串儲存格之列或只有無表頭欄有值之列讀為空白列；值一律讀為字串，日期儲存格讀為'YYYY-MM-DDTHH:mm:ss.SSS'(即Excel儲存格之年月日時分秒，不含時區，與執行環境時區無關)，日期型之表頭亦同。寫入時只保留opt.keys之欄，缺欄之值為空字串；個別空白列照常寫入，全部列皆空白時拒絕；附加模式會重建既有之列物件。多次呼叫時依完成先後寫入，後完成者覆蓋

Returns:

回傳Promise，resolve回傳上傳後之表格數據陣列，與opt.rows為同一陣列，resolve時表格已更新，opt.rowsChange於其後觸發；reject時本方法不寫入表格數據(beforeUpload自身對外之改動不回復)，亦不觸發opt.rowsChange。reject之值：本方法產生者為錯誤物件{ msg, err }，msg為下列代碼，err為說明(除'no file'、'can not read excel'與'can not read file'外皆以'[w-aggrid-vue] uploadData: '為前綴)：使用者於選檔視窗取消時msg為'no file'、err為'file selection was canceled'，此時未呼叫beforeUpload，呼叫端可依msg判斷為取消而不提示；選檔或讀取檔案失敗(例如檔案過大)時msg為'can not read file'、err為wsemi之錯誤物件；無法讀取Excel時msg為'can not read excel'；指定之分頁不存在時msg為'can not get data from sheet'；beforeUpload回傳值不合約定時msg為'invalid beforeUpload return'；無可寫入之列或全部列於opt.keys之值皆為空時msg為'no data'，呼叫端可視為無作為；無任一列有opt.keys之值時(例如首列非表頭、表頭與opt.keys不符、讀到隱藏分頁)msg為'no matching keys'。beforeUpload自身拋錯或reject時，其錯誤原樣reject且保持參照
