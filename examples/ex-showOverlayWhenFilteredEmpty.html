showOverlayWhenFilteredEmpty
example code
opt.showOverlayWhenFilteredEmpty(預設 true)：數據不為空而過濾(表頭過濾或 filterall)使顯示列數為 0 時，顯示 localeText 之 noRowsToShowFiltered 提示覆蓋層(language 為 zh-tw 之內建文字為「無符合過濾條件之資料」)，顯示列數回到大於 0 時隱藏；數據本身為空(opt.rows 為空陣列)時仍顯示 noRowsToShow，呼叫端以 getApi().showLoadingOverlay() 顯示之載入中覆蓋層不會被蓋掉。文字可由 opt.localeText 覆寫(見 localeText 範例)。
本範例左右兩表同樣數據、同樣於 1 秒時以表頭過濾使顯示列數為 0、3 秒時清除過濾；左表為預設(true)，右表設為 false。
破壞性變更：此提示覆蓋層預設開啟。以往表頭過濾使顯示列數為 0 時，表格只剩表頭與空白而無提示(右表即為舊行為)；filterall 使數據為空時，顯示的是 noRowsToShow(與數據本身為空無法區分)。現在兩者皆改為顯示 noRowsToShowFiltered。欲恢復舊行為請設 opt.showOverlayWhenFilteredEmpty = false。
showOverlayWhenFilteredEmpty: true(default)
