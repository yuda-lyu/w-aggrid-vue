localeText
example code
opt.localeText 以 ag-grid 之 locale 鍵覆寫表格文字，值為字串(可為空字串)。查找順序為先查 opt.localeText，查無再用 opt.language 之內建字典，故未給予時行為不變。
本範例(language 為 zh-tw)覆寫兩個提示文字：
  • noRowsToShow：數據為空(opt.rows 為空陣列)時顯示，內建文字為「無資料可顯示」，本範例覆寫為「無數據」。
  • noRowsToShowFiltered：本套件新增之鍵，數據不為空而過濾使顯示列數為 0 時顯示，內建文字為「無符合過濾條件之資料」，本範例覆寫為「無查詢結果，請更換關鍵字或查詢條件。」。
時序：1 秒時表頭過濾使顯示列數為 0，2 秒時清除過濾，3 秒時 opt.rows 改為空陣列。
破壞性變更：過濾使顯示列數為 0 之提示覆蓋層預設開啟(opt.showOverlayWhenFilteredEmpty 預設為 true)。以往表頭過濾使顯示列數為 0 時，表格只剩表頭與空白而無提示；filterall 使數據為空時，顯示的是 noRowsToShow(與數據本身為空無法區分)。現在兩者皆改為顯示 noRowsToShowFiltered。欲恢復舊行為請設 opt.showOverlayWhenFilteredEmpty = false(見 showOverlayWhenFilteredEmpty 範例)。
