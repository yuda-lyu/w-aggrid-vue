元件根節點(class 為 CompCssWAggridVue)帶有 DOM 屬性 state，表示表格是否已完成淡入。表格建立後外層容器有 0.5 秒之淡入(opacity 0 → 1)，使用端若在淡入期間量測或截圖(例如 e2e 之像素比對)，畫面尚未落定。
  • state="showing"：初值。表格尚未就緒，或已就緒而淡入尚在進行(含淡入結束後等待容器尺寸穩定並補繪之期間)。
  • state="shown"：淡入已結束。單向轉換，之後不再回到 showing。
淡入期間若元件根節點之尺寸有改變(例如所在容器以 CSS 過場移動並改寬)，此期間補繪之儲存格字形像素在不同次建立間有次像素差異且不自行收斂；故元件會在淡入結束且尺寸穩定(最後一次尺寸變化後 0.35 秒無再變化)後自動以 api.refreshCells({ force: true }) 重繪一次儲存格，重繪完成才落定為 shown(自訂 cell-render slot 之儲存格因此被重建一次)。淡入期間尺寸未改變者不重繪，淡入結束即為 shown。
使用端等待落定後再量測或截圖： await page.waitForSelector('.CompCssWAggridVue[state="shown"]')
